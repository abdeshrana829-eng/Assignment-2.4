1. Sample Buggy HTML File (Before)Below is a typical buggy HTML file containing missing closing tags, incorrect tag nesting, missing quotes on attributes, and unclosed elements.HTML<!DOCTYPE html>
<html>
<head>
    <title>Debugging Exercise
</head>
<body>
    <h1>Welcome to My Buggy Page
    <p>This is a paragraph with a <b>bold word and an unclosed anchor tag.
    
    <ul>
        <li>Item 1
        <li>Item 2
        <li>Item 3</i>
    </ul>

    <div class=container>
        <img src="banner.jpg" alt=Banner Image>
        <p>Unclosed paragraph div container.
    </div>

</body>
</html>
2. Identified Errors & IssuesWhen you run this file through an HTML validator (like the W3C Markup Validation Service) or inspect it in browser DevTools, the following errors appear:Missing Closing Tags:<title> is never closed (</title>).<h1> is missing its closing tag (</h1>).The first <p> tag is missing its closing tag (</p>).List items (<li>) are missing closing tags (</li>), though HTML5 permits this, it's poor practice.Incorrect Nesting:An italic/bold closing tag (</i>) is accidentally placed inside a <ul> list instead of a proper inline tag closure.Missing Attribute Quotes:class=container is missing quotes (should be class="container").alt=Banner Image has unquoted multi-word text (should be alt="Banner Image").Structural Issue:Missing <html> language attribute (<html lang="en">).3. Corrected & Properly Indented HTML File (After)Here is the fully debugged, valid, and properly structured version of the code:HTML<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Debugging Exercise - Resolved</title>
</head>
<body>
    <h1>Welcome to My Debugged Page</h1>
    <p>This is a paragraph with a <b>bold word</b> and a properly closed anchor tag.</p>
    
    <ul>
        <li>Item 1</li>
        <li>Item 2</li>
        <li>Item 3</li>
    </ul>

    <div class="container">
        <img src="banner.jpg" alt="Banner Image">
        <p>Properly closed paragraph inside the div container.</p>
    </div>
</body>
</html>
4. How to Inspect & Validate (Step-by-Step for Submission)Browser DevTools Inspection:Open your buggy HTML file in your browser (Chrome/Edge/Firefox).Right-click anywhere on the page and select Inspect (or press Ctrl+Shift+I / Cmd+Option+I).Navigate to the Elements panel. Notice how the browser's HTML parser tries to "guess" and auto-correct missing tags (often rendering elements outside containers where you didn't intend).HTML Validation Tool:Go to the W3C Markup Validator.Choose the Validate by Direct Input tab, paste your "Before" code, and click Check. Review the red error logs generated by the validator.Repeat with the "After" code to confirm a clean bill of health ("Document checking completed. No errors or warnings to show.").1.
